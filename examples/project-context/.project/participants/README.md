# Participants

Each subdirectory is a participant pack: a shared boundary document describing
how this project and one collaborator (service, agent, team, tool) work
together — what the participant offers, what the project offers back, what
each side is and is not authoritative for.

A pack is optional enrichment. Deleting one must not corrupt the project.

Acceptance flow (friendly, not legalistic):

```text
PROJECT:      Here are the Play-Nice contracts.
PARTICIPANT:  I accept the applicable contracts.
PARTICIPANT:  Here is useful information that will help us work together.
PROJECT:      Validate + classify + store as a participant pack.
FUTURE:       Load relevant participant knowledge automatically.
```

See the `project-context-and-participant-packs` contract in the Play-Nice
library. No secrets in packs — symbolic references only.
